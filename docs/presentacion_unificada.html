Persistencia y Sistema de Respaldos

Persistencia en Base de Datos

  • PostgreSQL 15: Sistema robusto
  • Volúmenes Docker: Datos persistentes
  • ACID Transactions: Integridad garantizada
  • WAL: Recuperación ante fallos
Volumen: postgres_data:/var/lib/postgresql/data

Respaldos Automáticos

  • Horario: Diariamente a las 02:00 AM
  • Ubicación: /home/admin/api-recetas/backups
  • Rotación: A las 02:30 AM (elimina > 14 días)
  • Formato: pg_dump con UTF-8
Respaldo: backup_full.sh
Cómo Restaurar desde Backup:
# 1. Copiar backup al contenedor
docker cp backup.sql postgres_container:/tmp/restore.sql

# 2. Conectar al contenedor
docker exec -it postgres_container bash

# 3. Restaurar la base de datos
psql -U postgres -d recetas_db -f /tmp/restore.sql

# 4. Verificar restauración
psql -U postgres -d recetas_db -c "SELECT COUNT(*) FROM receta;"

Recomendación: Introducir Redis para sesiones/caches y configurar réplicas de lectura en PostgreSQL cuando la carga aumente.

Preguntas Técnicas Frecuentes

  • API REST: Comunicación mediante HTTP/HTTPS
  • JSON: Formato de intercambio de datos
  • Axios: Cliente HTTP en React
  • CORS: Configurado para cross-origin
  • JWT en Headers: Authorization: Bearer <token>

  1. Usuario envía email/password a /auth/login
  2. Backend valida credenciales con BCrypt
  3. Si es válido, genera JWT firmado
  4. Frontend almacena token en localStorage
  5. Cada petición incluye token en header
  6. Backend valida token en cada request
  7. Si válido: acceso; si no: 401

SÍ, completamente persistente:

  • Volumen nombrado: postgres_data:/var/lib/postgresql/data
  • Sobrevive a: docker-compose down y up
  • Se pierde solo si: Eliminas explícitamente el volumen
  • Backups diarios automáticos (02:00 AM)
  • Rotación de backups (retención 14 días)

SÍ, con ajustes recomendados:

  • Backend: Stateless, múltiples réplicas con load balancer
  • Database: Escalado vertical inmediato, horizontal con réplicas
  • Archivos: CDN con S3/MinIO
  • Caché: Redis para sesiones compartidas
  • Capacidad: Hasta 100K usuarios concurrentes con optimización
